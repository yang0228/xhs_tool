# 个人创作工作台使用指南

沿用“采集、素材库、创作、发布”四个入口。自动发布和自动抓取指标仍不提供，发布由你在小红书创作中心完成。

## 升级现有实例

先备份数据库、R2 文件和浏览器加密备份，再按 README 安装锁定依赖、执行 `alembic upgrade head` 并重新构建扩展。新增迁移仅添加字段和索引表，不解密旧数据。开发验证只操作隔离测试 schema，没有自动迁移你的使用中实例。

备份现在使用内部载荷/记录 v2，密码加密外壳保持 v1；新版可以读取旧 v1 文件。旧版扩展不能读取新版载荷，请同步升级浏览器端和后端。

## 从选题到图文

1. 创作页点击“新建选题”，填写题目即可同步保存，正文可暂时留空。状态包括选题、创作中、待发布、已发布；主题标签和计划日期可随时调整。
2. 设置中读取并填写“个人创作档案”，最多三篇参考，每篇最多 2,000 字符。回到单篇点击“使用个人风格”，保存该篇采用的风格快照；档案后续修改不会自动改变已采用的快照。
3. 填写单篇简报，或从素材库带入多份素材。普通写作可以直接继续；改写及带引用写作会使用所选风格。
4. 在图文卡片中从正文生成分页，选择清单或步骤、配色及配图。每篇最多 100 页，超出时请拆成多篇，原文不会截断。支持修改文字、拆页和排序，预览通过后可逐张下载 PNG。复杂 Markdown 按纯文本展示，不支持自由画布或 HTML。
5. 默认尺寸为 1080 × 1440。标题过长、正文溢出、配图失效时会阻止导出，按提示拆页或调整文字。正文修改后卡片保留人工编辑，需要重新生成，或明确确认已核对现有卡片并保存。

## 可选 RAGFlow

本项目通过 HTTP 接入一个独立 RAGFlow，不随应用自动安装其解析、检索或模型服务。接口适配参考固定版本 [v1.0.0-rc2 的官方 HTTP 文档](https://github.com/infiniflow/ragflow/blob/v1.0.0-rc2/docs/references/http_api_reference.md)。后端回归测试模拟远端 HTTP；另已用本地 ARM64 部署和 BGE-M3 验证纯文本上传、解析、检索及撤销。其他部署版本、解析器和检索质量仍需在实际实例上验证，详见[验证记录](verification.md)。

### 配置

在 RAGFlow 创建数据集并选择解析器和嵌入模型，取得数据集 ID 和服务 API Key。扩展“测试连接与身份”会显示当前账号 UUID。项目根目录 `.env` 中填写：

```dotenv
RAGFLOW_URL=http://127.0.0.1:9380
RAGFLOW_API_KEY=填写服务密钥
RAGFLOW_DATASETS='{"当前账号UUID":"数据集ID"}'
RAGFLOW_INDEX_REVISION=v1.0.0-rc2-v1
```

URL 不含 `/api/v1`，必须能从 FastAPI 所在机器访问。绑定由后端管理；浏览器无法指定其他账号的数据集或读取服务密钥。不同账号应使用不同数据集。修改解析器、嵌入模型或关键索引配置时，调整 `RAGFLOW_INDEX_REVISION` 并重新同步。

重启后端后，在扩展设置中检查知识库配置，阅读明文范围说明，再启用“允许 RAG 保存所选素材的明文副本”。此开关按连接身份在本机保存。

### 同步、写作与删除

- 启用后，新采集素材保存成功会同步索引；失败时原素材仍已保存，可在素材库重试。旧素材可多选补建，也可展开单篇索引区查看解析状态。
- 同步需要浏览器解锁并能够解密素材，正文最多 200,000 UTF-8 字节。旧素材若采用不同的内容哈希格式，需要重新采集或粘贴保存，不能跳过哈希核对。
- 解析交给 RAGFlow；已接受的任务可以在浏览器关闭后继续执行，尚未成功上传的全文需要重新解锁并同步。本项目不运行后台上传队列。
- 在编辑器点击“生成带引用提纲/正文”会自动检索，也可先检索并排除不需要的片段。默认最多六个片段、总计 8,000 字符；可限定当前关联素材。
- 正文和来源均作为建议，明确采用后才修改草稿，并可撤销。AI 引用编号受限于本次来源，但这不等于事实正确性验证，仍需对照原文核对。
- 流式生成中断或缺少完成确认时，已显示文字保留供核对，但不能直接采用；请重新生成。
- 写作请求会重新取得有效片段；如果来源不再出现在本次检索中，提示重新检索，而不是继续使用旧来源。
- 撤销索引或删除素材会立即排除其检索资格。远端删除失败保留清理记录，可在设置中“重试远端清理”；显示未清理数量时，副本仍可能存在于 RAGFlow。
- 关闭同步只停止新增明文副本；已存在的副本需要主动撤销。RAGFlow 如使用外部模型，片段或查询会发送给该提供方，请按自己的部署选择配置。

素材密文、草稿、档案和简报仍保存在 PostgreSQL；RAG 明文副本位于 RAGFlow，AI 请求会暂时使用所需文本。主密钥不发送给后端。其他设备访问同一账号的加密草稿时，需要通过加密备份安全恢复原本地密钥。

## 发布准备与快照

发布页提供一周排期和未排期列表，日期仅作个人安排。今日、逾期等提醒只在工具内显示，不代表平台预约发布。

发布准备以已保存草稿的具体版本为准。先核对来源，再导出 ZIP：`title.txt`、`content.txt`、`sources.md`、按顺序编号的卡片 PNG，最后追加未嵌入卡片的所选原图。总文件体积最多 100 MiB；任意图片或渲染失败会使整包导出失败。

导出前后均核对服务器版本。其他设备更新了草稿时，需要重新加载和导出；正在编辑的本机内容先保存再进入发布准备。

手动发布后填写实际链接和实际发布时间。登记时保存加密内容快照、主题/模板和版本，重复提交相同草稿链接不会创建两条记录。以后修改或删除草稿，历史快照和指标仍保留；所引用的原图受到删除保护。旧发布记录没有快照时会明确显示，不能自动补出当时内容。

在历史快照中可预览生成的图文，并按发布时的选择顺序查看和下载原图；备份恢复后的图片 ID 会按发布记录映射。另一个窗口切换账号或后端后，原页面的带入创作、排期修改及历史图片请求会拒绝继续，请重新打开对应页面。

## 指标与复盘

手动记录累计浏览、点赞、评论、分享、收藏，可指定实际观察时间，留空表示现在。观察时间必须带时区，且不能早于实际发布或晚于当前时间。界面日期控件按本机时区转换。

CSV 使用本工具格式，单次最多 500 行，不承诺兼容平台任意导出文件：

```csv
xhs_post_url,collected_at,view_count,like_count,comment_count,share_count,collect_count
https://xhslink.com/a/你的真实链接,2026-10-17T10:00:00+08:00,120,6,2,1,3
```

也可用 `post_id` 代替链接，或同时提供两者并保持指向同一条记录。先预览校验，再确认整批导入；错误、未知/越权链接或冲突会阻止整批写入。相同记录、观察时间及数值的重复导入跳过；同一时点数值不同则报冲突。

主题和模板比较采用发布后 24 或 72 小时前后 3 小时内最近的一次观察，展示实际观察时长、有效样本数与缺数据数。没有对应数据就留空，不把最新累计数冒充某时点数据；零浏览不计算比率。主题允许重叠，分组样本数不能直接相加。

复盘建议由现有统计按规则生成，分为数据观察与下一步尝试，不另行调用 AI。样本少会明确标出，不做因果归因或爆款评分；可把建议转为新的选题继续创作。

## 备份边界与恢复中断

备份包含加密档案、草稿上下文、计划日期、卡片参数、发布快照和指标；不包含 API Key、RAGFlow 密钥、R2 图片文件或 RAGFlow 索引数据。分别管理服务和文件备份。

恢复继续保留已有记录与本机编辑。素材因去重映射到其他 ID 时，浏览器会解密、修正新恢复上下文的引用，再加密保存；中断会保留原密文和待修复记录，可在设置重试“恢复引用”。遇到较新的冲突草稿会停止该项修复，不覆盖用户修改；先在草稿中核对来源，再重试。

备份不导入外部文档绑定到新实例，需从解锁的浏览器重新建立索引。同一实例已有的有效绑定不因普通备份恢复自动删除。
